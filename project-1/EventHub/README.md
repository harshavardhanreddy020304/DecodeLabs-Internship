# 🎉 EventHub – Responsive Event Management & Ticket Booking Platform

> DecodeLabs Full Stack Development Internship – Project 1  
> Built using **HTML5, CSS3, and JavaScript**

---

## 📌 Project Overview

**EventHub** is a responsive frontend web application designed for discovering, exploring, and booking events. The project demonstrates modern frontend development principles using semantic HTML, responsive CSS, and interactive JavaScript without any frameworks.

This project was developed as part of **DecodeLabs Full Stack Development Internship – Project 1**, focusing on responsive web design, accessibility, and clean user interface development.

---

## 🎯 Project Objectives

- Develop a responsive multi-page website
- Follow Mobile-First Design principles
- Use Semantic HTML5 elements
- Build responsive layouts with CSS Grid and Flexbox
- Implement JavaScript for user interaction
- Create a modern and user-friendly UI
